# Living Skills Lineage

**A living archive of human knowledge.**

Living Skills Lineage is a human-first digital home for the people who carry traditional and endangered knowledge, the lineages that shaped it, and the next generation who may keep it alive.

> Don't build a platform about skills. Build a place where one human being can encounter another human being — and where knowledge has a chance to cross that distance before it disappears.

## Product principles

- **People before content.** A practitioner is never raw material for a platform.
- **Original voice stays.** Translation helps people listen; it does not replace the speaker.
- **Lineage is human.** Show who taught whom, with consent, rather than reducing relationships to metadata.
- **Evidence before urgency.** Claims such as “last practitioner” require a source and verification date.
- **Not everything belongs online.** Communities must be able to restrict sacred, private or non-commercial knowledge.
- **Understanding before transaction.** Learning, visits, apprenticeships and commerce support preservation; they do not define the experience.
- **AI stays quiet.** Use it for translation, transcription, discovery and documentation — never to replace the practitioner.

## Current prototype

The first interactive prototype includes a documentary-style home experience, living-knowledge story cards, practitioner/skill narrative pages, a human lineage view, an endangered-knowledge framework, the “Someone should know this after me” concept, and preservation/support pathways.

The sample stories are intentionally labelled **prototype stories**. They demonstrate the product experience and do not invent named practitioners or make unsupported “last practitioner” claims.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Next production milestones

1. Research and consent protocol for real practitioner stories.
2. Evidence model for preservation status and lineage claims.
3. Structured data layer for regions, communities, skills, variants, practitioners and relationships.
4. Practitioner-controlled permissions for public, learning-only, commercial-restricted, community-only, sacred/private and do-not-document knowledge.
5. Multilingual audio/video capture and human-reviewed translation workflow.
6. Verified nomination and editorial review system.
7. Pilot with a small number of deeply documented traditions before geographic expansion.

## Technology

React + Vite. The prototype is deliberately lightweight so the experience remains fast, accessible and easy to evolve.
